-- API root set for the pickles package (the in-circuit kimchi verifier, so far its
-- linearization slice). Consumed by the workspace dead-code pass
-- (formal/scripts/deadcode.sh); the axiom audit is pickles/scripts/check_axioms.lean.
--
-- The roots ARE the axiom gate's roots: the two circuit theorems, one per side of the
-- cycle, and the two reflection endpoints they rest on. Everything else the package
-- proves or defines — the token language, the machine, its simulation laws, the
-- environments, the certificates — must stay reachable from these four, which is what
-- keeps the dead-zero contract meaningful here.
Pickles.Reflect.circuit_gateLinearization_fp
Pickles.Reflect.circuit_gateLinearization_fq
Pickles.Reflect.evaluate_fpTokens
Pickles.Reflect.evaluate_fqTokens
