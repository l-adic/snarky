-- API root set for the snarky package (the deep-embedded circuit DSL).
-- Consumed by the workspace dead-code pass (formal/scripts/deadcode.sh). The axiom audit
-- lives in scripts/check_axioms.lean (the interpreter laws and the gadget laws).
--
-- The declared surface is the PORT surface: the Lean counterparts of the PS module
-- exports (each module docstring's D7 name map), the Lean-only laws the embedding exists
-- to state, and the `Example` exhibits (showcase circuits and the run helpers the
-- anonymous `decide` examples consume — invisible to any constant walk). Internal
-- machinery — witness cores, private lemmas, the reduction pipeline's helpers — is
-- deliberately NOT rooted: it must stay reachable from this surface, which is what keeps
-- the dead-zero contract meaningful for this package. `Snarky.*` declarations are
-- audited by the workspace pass like every other package's.
